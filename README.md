# Credit Risk Analysis Report

## Overview
### This analysis evaluates a logistic regression model for predicting credit risk and determines if a loan is healthy or high-risk based on historical data. 

## Model Results
- 99% accuracy 
- 86% precision for high-risk loans
- 94% recall of the high-risk loans

## Conclusion
### The logistic regression model effectively predicts credit risk, achieving high accuracy and recall for identifying high-risk loans. While it slightly misclassifies some healthy loans as high-risk, its strong recall ensures minimal financial risk exposure. The model is suitable for credit risk assessment, though further optimization could improve precision.
